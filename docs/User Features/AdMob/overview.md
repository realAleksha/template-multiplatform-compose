# AdMob Feature

The AdMob feature provides a way to integrate Google AdMob advertisements into your multiplatform application.
It supports Banners, Native ads, Interstitial, and Rewarded ads.

Under the hood, it uses the [KMP-Google-AdMob](https://github.com/LexiLabs-App/KMP-Google-AdMob) library which unifies AdMob SDKs for Android and iOS.
On other platforms (Desktop, Web), ads are currently stubbed and will not be displayed.
